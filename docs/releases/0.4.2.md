# ProbRAW 0.4.2

ProbRAW 0.4.2 is a reliability release for the ICC workflow, the ArgyllCMS
profiling interface, session paths and the updater.

## ICC Profiling and QA

- The interface explains `colprof` options more clearly: shaper + matrix `-as`
  as the recommended preset, Medium quality and `-u -R` arguments.
- cLUT modes `-al` and `-ax` remain available, but are treated as advanced
  options with an overfit warning for ColorChecker 24.
- `draft` profiles are registered in the session, but do not autoactivate.
- `rejected` profiles also do not autoactivate and now require explicit
  confirmation if the operator wants to use them for diagnosis or comparison.
- Profile metadata reports the real ArgyllCMS model (`argyll_shaper_matrix`,
  `argyll_lab_clut`, etc.) instead of always reporting `matrix3x3`.
- The global progress bar shows phase, detail and percentage during advanced
  profile generation.

## Sessions and Paths

- Paths persisted in `session.json` are confined to the session root so opening a
  project cannot create or use directories outside it on another machine.
- ICC profiles generated or registered in the session apply coherently to the
  active image and RAW sidecars.
- The dark interface improves contrast, focus and readability for radios,
  checkboxes, path fields, compact buttons and diagnostic panels.

## Updater and Installers

- The update assistant sanitizes installer and checksum names before writing to
  disk.
- Asset selection avoids packages for other platforms and does not use wheels or
  source tarballs as installers.
- Linux can launch `.rpm` installers via `dnf`, `yum` or `rpm`.
- Installer publication documentation lists the specific checks for this release.
