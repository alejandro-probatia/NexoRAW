# ProbRAW 0.3.21

ProbRAW 0.3.21 is a corrective release replacing 0.3.20 when ICC profiling
failed with a manually marked chart and another selected capture fell back to
`fallback` detection.

## ICC Profiling

- Charts with manual detections are kept in the training set before reserving
  captures for validation. This lets an invalid automatic capture become
  validation/skipped data without blocking generation when the manually marked
  chart provides valid samples.
- Profiling reports now include neutral-row a*/b* residuals and non-blocking
  recommendations for lighting, chart reference, profile model and independent
  validation.
- Missing independent validation keeps the ICC as a usable `draft` instead of
  making the run a blocking error.
- Camera RGB display-balance compensation is not applied when previewing through
  a generated input ICC, avoiding blue casts in the application.

## Preview And Histograms

- The tone-curve histogram is visible from the start even when the curve effect
  is disabled.
- The tone-curve histogram reflects applied tonal and curve adjustments, as in a
  photo editor, so the operator can see how pixel distribution changes.
- While dragging the curve, the tonal histogram is calculated in the background
  and only the latest valid result is painted. The preview color pipeline is not
  changed.
- The viewer histogram reuses the already-computed colorimetric patch when it is
  available, reducing repeated conversions without changing precision.

## Verification

- Focused workflow and GUI tests for manual detection, fallback handling,
  asynchronous tone-curve histograms and histogram reuse.
- GUI benchmark on a synthetic `1440x2160` image: curve-drag emission median
  `0.183 ms`, max `0.43 ms`; interactive rendering remains in the background.
