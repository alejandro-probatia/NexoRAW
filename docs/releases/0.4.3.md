# ProbRAW 0.4.3

ProbRAW 0.4.3 strengthens ICC profiling from RAW/DNG originals, manual chart
marking and Lab diagnostic tools.

## ICC Profiling and Charts

- ICC generation is tied to original RAW/DNG files, not derived TIFF files.
- Each session ICC is registered together with the calibrated recipe that must
  accompany that profile to keep lighting, exposure and development coherent.
- Manual chart marking shows the 24 exact central reading regions. Regions are
  smaller and can be shifted away from borders, dust, glare or stains before
  saving the detection.
- Pending-QA and rejected profiles never autoactivate and use localized labels in
  the Spanish interface.

## Lab Samples

- The Lab eyedropper requires readings from a real-pixel image source.
- If sharpness, noise or chromatic-aberration adjustments require an exact
  real-size recalculation, ProbRAW runs it before saving the sample.
- Compact sample cards use space more efficiently, allow sample selection,
  marker-color changes and active-sample highlighting in the viewer.
- The Lab a*b* set graph can be opened in an enlarged dialog.

## Interface and Workflow

- Thumbnails always show the filename above saved-profile badges.
- The task bar keeps phase and detail information visible during background work
  to reduce the impression of a blocked application.
