# ProbRAW 0.3.21

ProbRAW 0.3.21 es una release correctiva para reemplazar la 0.3.20 cuando el
perfilado ICC fallaba con carta marcada manualmente y otra captura seleccionada
caia en deteccion `fallback`.

## Perfilado ICC

- Las cartas con deteccion manual se mantienen en el conjunto de entrenamiento
  antes de reservar capturas para validacion. Asi, una captura automatica no
  valida puede quedar como validacion/omision sin bloquear la generacion si la
  carta marcada manualmente aporta muestras validas.
- Los informes de perfilado anaden residuo a*/b* en la fila neutra y
  recomendaciones no bloqueantes sobre iluminacion, referencia de carta, modelo
  de perfil y validacion independiente.
- La ausencia de validacion independiente deja el ICC como `draft` utilizable en
  vez de convertir el proceso en error bloqueante.
- La compensacion visual de balance de camara no se aplica cuando la preview
  usa un ICC de entrada generado, evitando dominantes azules en la aplicacion.

## Preview E Histograma

- El histograma de curva aparece desde el inicio aunque la curva este
  desactivada.
- El histograma de curva refleja los ajustes tonales y de curva aplicados, como
  en un editor fotografico, para que el operador vea como cambian los pixeles.
- Durante el arrastre de la curva, el histograma tonal se calcula en segundo
  plano y solo se pinta el ultimo resultado valido. La ruta colorimetrica de
  preview no cambia.
- El histograma del visor reutiliza el parche colorimetrico ya calculado cuando
  esta disponible, reduciendo conversiones repetidas sin alterar precision.

## Verificacion

- Pruebas focalizadas de workflow y GUI para deteccion manual, fallback,
  histograma de curva asincrono y reutilizacion de histograma.
- Benchmark GUI sobre imagen sintetica `1440x2160`: emision de arrastre de
  curva con mediana `0.183 ms` y maximo `0.43 ms`; el render interactivo sigue
  en segundo plano.
