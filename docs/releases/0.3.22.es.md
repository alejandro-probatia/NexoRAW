# ProbRAW 0.3.22

ProbRAW 0.3.22 es una release correctiva para el flujo de seleccion de perfiles
ICC de entrada generados en la sesion. La correccion permite usar manualmente
un perfil marcado como `rejected` por QA sin volver a permitir activaciones
automaticas ambiguas.

## Perfiles ICC De Sesion

- Los perfiles ICC `rejected` siguen bloqueados para autoactivacion.
- La seleccion explicita desde el combo de perfiles de sesion, el menu de carga
  manual o "Usar ICC generado" puede activarlos.
- El combo de perfiles de sesion queda disponible si hay perfiles registrados,
  aunque el modo activo sea un espacio RGB estandar.
- La activacion manual queda reflejada en estado/log para mantener trazabilidad.

## Persistencia RAW

- La mochila RAW guarda ruta e identificador del perfil ICC activo.
- Al recargar una imagen o reabrir una sesion, un ICC `rejected` solo se
  restaura si el identificador guardado apunta a la misma ruta.
- Una imagen sin mochila o con ID incoherente limpia el ICC activo en vez de
  conservar una seleccion anterior.
