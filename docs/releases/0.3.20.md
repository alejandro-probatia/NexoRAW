# ProbRAW 0.3.20

ProbRAW 0.3.20 publishes the session-path and monitor color-management fixes
needed for the Windows workflow after 0.3.19.

## Session Paths And ICC Profiling

- New sessions align the browser, chart reference folder and derivative TIFF
  export folder with the active project instead of inheriting paths from another
  project.
- Manual chart marking can generate an ICC profile even when the previous chart
  detector had no usable automatic candidates.
- ICC profiling errors report why chart captures were skipped, including
  detection mode, confidence, threshold and warnings.

## Monitor Color Preview

- Monitor ICC management remains display-only. Exported TIFF files keep the
  selected input ICC and never use the monitor profile.
- When ProbRAW converts preview pixels to the active monitor ICC with LittleCMS,
  the Qt image is handed over as device RGB with no extra `QColorSpace` tag.
  This avoids a second conversion by Qt or the compositor.
- Active monitor ICC detection is cached per screen and display settings, which
  reduces repeated system profile probes during thumbnails and interactive
  refreshes.

## RAW And Auditability

- RAW backend validation rejects unsupported settings instead of applying silent
  substitutions.
- Auto-oriented RAW geometry is kept separate from user-authored crop, rotation
  and leveling state for clearer review and reproducibility.

## Verification

- Focused GUI/session and monitor-display tests passed for project path
  alignment, untagged device-RGB preview buffers after LittleCMS monitor
  conversion and explicit failures when monitor ICC conversion cannot be
  performed.
- Full suite during the Windows installer build: `473 passed, 2 warnings`.
- Strict external tools check passed with ArgyllCMS 3.2.0, ExifTool 12.92 and
  standard sRGB/Adobe RGB/ProPhoto ICC profiles.
- Packaged smoke checks passed: `probraw --version`, `probraw --help`,
  `probraw check-tools --strict`, `probraw check-c2pa` and
  `probraw check-amaze`.
- AMaZE is active through `rawpy-demosaic 0.10.1`, LibRaw 0.18.7 and
  `DEMOSAIC_PACK_GPL3=True`.
