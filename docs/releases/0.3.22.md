# ProbRAW 0.3.22

ProbRAW 0.3.22 is a corrective release for the session-generated input ICC
profile selection workflow. It allows an operator to manually use a profile
marked as QA `rejected` without reintroducing ambiguous automatic activation.

## Session ICC Profiles

- `rejected` ICC profiles remain blocked for automatic activation.
- Explicit selection from the session-profile combo, the manual load menu or
  "Use generated ICC" can activate them.
- The session-profile combo remains available when profiles are registered,
  even if the active mode is a standard RGB space.
- Manual activation is recorded in status/log output to preserve traceability.

## RAW Persistence

- RAW sidecars store both the active ICC profile path and profile identifier.
- When reloading an image or reopening a session, a `rejected` ICC is restored
  only if the stored identifier points to the same path.
- An image without a sidecar or with an inconsistent ID clears the active ICC
  instead of keeping a previous selection.
