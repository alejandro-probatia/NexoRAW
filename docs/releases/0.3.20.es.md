# ProbRAW 0.3.20

ProbRAW 0.3.20 publica las correcciones de rutas de sesion y gestion de color
de monitor necesarias para el flujo Windows posterior a 0.3.19.

## Rutas De Sesion Y Perfilado ICC

- Las sesiones nuevas alinean el navegador, la carpeta de referencias de carta
  y la carpeta de exportacion TIFF derivada con el proyecto activo en lugar de
  heredar rutas de otro proyecto.
- El marcado manual de carta puede generar un perfil ICC aunque el detector
  automatico anterior no tuviera candidatos utilizables.
- Los errores de perfilado ICC explican por que se descartaron capturas de
  carta, incluyendo modo de deteccion, confianza, umbral y avisos.

## Preview De Color De Monitor

- La gestion ICC de monitor sigue siendo exclusiva de visualizacion. Los TIFF
  exportados conservan el ICC de entrada seleccionado y nunca usan el perfil de
  monitor.
- Cuando ProbRAW convierte pixeles de preview al ICC de monitor activo con
  LittleCMS, la imagen Qt se entrega como RGB de dispositivo sin etiqueta
  `QColorSpace` adicional. Esto evita una segunda conversion por Qt o el
  compositor.
- La deteccion del ICC de monitor activo queda cacheada por pantalla y ajustes
  de visualizacion, reduciendo consultas repetidas durante miniaturas y
  refrescos interactivos.

## RAW Y Auditabilidad

- La validacion del backend RAW rechaza ajustes no soportados en lugar de
  aplicar sustituciones silenciosas.
- La geometria RAW auto-orientada queda separada de recorte, rotacion y
  nivelado escritos por el usuario para mejorar revision y reproducibilidad.

## Verificacion

- Las pruebas GUI/sesion y de visualizacion de monitor pasaron para alineacion
  de rutas de proyecto, buffers de preview RGB de dispositivo sin etiqueta
  despues de la conversion LittleCMS al monitor y errores explicitos cuando no
  puede hacerse la conversion ICC de monitor.
- Suite completa durante la build del instalador Windows:
  `473 passed, 2 warnings`.
- Check estricto de herramientas externas correcto con ArgyllCMS 3.2.0,
  ExifTool 12.92 y perfiles ICC estandar sRGB/Adobe RGB/ProPhoto.
- Smoke checks empaquetados correctos: `probraw --version`, `probraw --help`,
  `probraw check-tools --strict`, `probraw check-c2pa` y
  `probraw check-amaze`.
- AMaZE activo mediante `rawpy-demosaic 0.10.1`, LibRaw 0.18.7 y
  `DEMOSAIC_PACK_GPL3=True`.
