# ProbRAW 0.4.1

ProbRAW 0.4.1 is a corrective Linux Arch/CachyOS release for the Lab sample
workflow and the application interface.

## Lab Sample Accuracy

- Saved Lab samples are marked pending as soon as the current render changes.
- Color, exposure and contrast edits recalculate saved readings from current
  real-pixel values before RGB/Lab values are published again.
- Partial interactive preview patches also trigger sample refreshes, avoiding
  stale values after visible image changes.
- RGB sample values are shown as standard integer 0-255 triplets.
- If an exact full-resolution recalculation is not available, the UI keeps the
  reading pending instead of publishing partial values.

## Interface

- The GUI now uses a neutral dark-gray theme on every supported desktop,
  independent of the system theme.
- The effective UI language is Spanish to avoid mixed-language surfaces while
  the translation catalog is incomplete.
- Precision and workflow explanations are moved behind compact information
  buttons where possible.
- Text contrast was adjusted for dark panels, cards, tables and status labels.
