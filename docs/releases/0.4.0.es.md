# ProbRAW 0.4.0

ProbRAW 0.4.0 anade diagnostico de muestras Lab para comparar colores medidos
sobre imagen real. El flujo nuevo es diagnostico: no altera recetas, pixeles,
perfiles activos ni TIFF exportados.

## Muestras Lab

- `Diagnostico > Muestras` anade un cuentagotas Lab para pixeles reales de la
  imagen cargada.
- Hay matrices de muestreo `1x1`, `3x3`, `5x5`, `9x9` y `17x17`.
- El visor muestra una lupa de pixel real durante la toma.
- Las muestras quedan numeradas en la imagen y en la tabla.
- Las muestras se persisten por imagen en `RAW.probraw.json`.

## Conjuntos De Muestras

- Las muestras pueden agruparse en conjuntos con nombre.
- Las vistas de tabla/fichas exponen campos editables de conjunto, nombre y
  nota.
- Los resumenes de conjunto informan RGB medio, Lab medio, C*, dispersion
  interna DE00, similitud porcentual y DeltaE frente al conjunto de referencia
  activo.
- La referencia comparativa se elige a nivel de conjunto; no hay una muestra
  primaria dentro de un conjunto.

## Diagnostico De Gamut

- El comparador de gamut por pares soporta modos Lab 3D y Lab 2D.
- Lab 2D usa un selector vertical de L* para inspeccionar cortes a*b*.
- Las muestras de perfil fuera de gama se marcan en los diagnosticos.
- Las lecturas Lab de muestras indican si la muestra queda dentro del perfil A,
  el perfil B y la gama comun.

## Alcance Colorimetrico

- Las lecturas Lab y DeltaE solo son rigurosas cuando la imagen usa un ICC de
  sesion generado por ProbRAW para la misma camara, receta e iluminante.
- Con perfiles ICC genericos, las lecturas siguen siendo trazables pero son
  diagnosticos orientativos del espacio asignado.
- Si la preview actual esta reducida, ProbRAW solicita carga a resolucion
  completa antes de guardar una muestra de color.
