# ProbRAW 0.4.0

ProbRAW 0.4.0 adds Lab sample diagnostics for real-image color comparison. The
new workflow is diagnostic: it does not alter recipes, pixels, active profiles or
exported TIFFs.

## Lab Samples

- `Diagnostico > Muestras` adds a Lab eyedropper for real pixels from the loaded
  image.
- Sampling matrices `1x1`, `3x3`, `5x5`, `9x9` and `17x17` are available.
- The viewer shows a real-pixel magnifier while sampling.
- Samples are numbered in the image and in the table.
- Samples are persisted per image in `RAW.probraw.json`.

## Sample Sets

- Samples can be grouped into named sets.
- The table/card views expose editable group, name and note fields.
- Set summaries report mean RGB, mean Lab, C*, internal DE00 dispersion,
  similarity percentage and DeltaE against the active reference set.
- The comparison reference is selected at set level; there is no primary sample
  inside a set.

## Gamut Diagnostics

- The pairwise gamut comparator now supports Lab 3D and Lab 2D modes.
- Lab 2D uses a vertical L* selector to inspect a*b* slices.
- Out-of-gamut profile samples are marked in diagnostics.
- Lab sample readings report whether the sample is inside profile A, profile B
  and their common gamut.

## Colorimetric Scope

- Lab and DeltaE readings are rigorous only when the image uses a
  ProbRAW-generated session ICC for the same camera, recipe and illuminant.
- With generic ICC profiles, the readings remain traceable but are informative
  diagnostics of the assigned space.
- If the current preview is reduced, ProbRAW requests full-resolution loading
  before saving a color sample.

## Documentation

- README, user manual, color pipeline, RAW/ICC methodology, architecture,
  reproducibility, comparison and roadmap were updated.
- New performance-improvement plan documented in English and Spanish.
- New diagnostic screenshots added for chart diagnostics, gamut comparison and
  Lab sample sets.
