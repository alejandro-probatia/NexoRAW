# ProbRAW 0.4.4

ProbRAW 0.4.4 consolida el trabajo de rendimiento de preview interactiva, el
ajuste de runtime y los instaladores Arch/Windows/Debian actualizados.

## Preview interactiva

- Las previews de viewport tras cambios recientes sin arrastre mantienen activo
  el histograma exacto y difieren las muestras colorimetricas hasta reposo.
- Los arrastres directos de sliders y curvas siguen evitando renders RAW
  completos desde vistas proxy y posponen trabajo exacto no visual hasta que la
  interaccion queda estable.
- El contrato de cola de preview incluye el flag de cache de ajustes de detalle
  usado por los tests de preemption de viewport.

## Ajuste de runtime

- `probraw tune-performance` informa deteccion CPU/RAM, politica de hilos
  acotada y variables de entorno para la maquina activa.
- Los hooks post-install de paquetes Linux ejecutan el ajuste cuando la CLI
  empaquetada esta disponible, escribiendo la politica de sistema de forma
  oportunista sin romper instalaciones.
- La deteccion de herramientas Linux incluye la ruta Arch `/usr/bin/vendor_perl`
  para que `perl-image-exiftool` satisfaga los checks estrictos del instalador
  sin cambios manuales de `PATH`.
- Se incluye `scripts/benchmark_preview_load.py` para medir carga real de
  preview, placeholders embebidos, conversion ICC de pantalla y modo 1:1
  opcional.

## Verificacion

- Suite local: `558 passed, 1 skipped, 2 warnings`.
- Compilacion Python: `python -m compileall -q src tests` completado sin
  errores.
- Validacion instalador Windows: `build_installer.ps1` con `-RequireAmaze`,
  `-StrictExternalTools` y wheel cp312 de `rawpy-demosaic`; smokes empaquetados
  para version, ayuda, `check-tools --strict`, `check-c2pa` y `check-amaze`.
- Validacion paquete Linux: build Debian/Ubuntu en WSL con `PYTHON=python3.11`,
  `PROBRAW_BUILD_AMAZE=1` y `PROBRAW_REQUIRE_AMAZE=1`; validado con
  `packaging/debian/validate_deb.sh`.
- Build paquete Arch: `probraw-0.4.4-1-x86_64.pkg.tar.zst` generado con AMaZE y
  perfil `arch-generic`; checksum verificado con `sha256sum -c`.
- Validacion de instalacion Arch en contenedor limpio: `probraw --version`,
  `check-tools --strict`, `check-amaze` y `check-c2pa`.
