# ProbRAW 0.4.4

ProbRAW 0.4.4 consolidates the interactive preview performance work, runtime
performance tuning and refreshed Arch/Windows/Debian installers.

## Interactive Preview

- Viewport previews after recent non-drag control changes keep exact histograms
  enabled while deferring colorimetric preview patches until idle.
- Direct slider and curve drags still avoid full RAW renders from proxy views and
  postpone exact non-visual work until the interaction settles.
- The preview queue contract includes the detail-adjustment cache flag used by
  viewport preemption tests.

## Runtime Tuning

- `probraw tune-performance` reports CPU/RAM detection, bounded thread policy and
  environment variables for the active machine.
- Linux package post-install hooks run the tuner when the packaged CLI is
  available, writing system policy opportunistically without failing installs.
- Linux tool discovery includes Arch's `/usr/bin/vendor_perl` package path so
  `perl-image-exiftool` satisfies strict installer checks without manual `PATH`
  edits.
- `scripts/benchmark_preview_load.py` is included for measuring real preview
  load, embedded placeholders, display ICC conversion and optional 1:1 timing.

## Verification

- Local test suite: `558 passed, 1 skipped, 2 warnings`.
- Python compilation: `python -m compileall -q src tests` completed without
  errors.
- Windows installer validation: `build_installer.ps1` with `-RequireAmaze`,
  `-StrictExternalTools` and the cp312 `rawpy-demosaic` wheel; packaged smokes
  for version, help, `check-tools --strict`, `check-c2pa` and `check-amaze`.
- Linux package validation: Debian/Ubuntu build under WSL with `PYTHON=python3.11`,
  `PROBRAW_BUILD_AMAZE=1` and `PROBRAW_REQUIRE_AMAZE=1`; validated with
  `packaging/debian/validate_deb.sh`.
- Arch package build: `probraw-0.4.4-1-x86_64.pkg.tar.zst` generated with AMaZE
  and the `arch-generic` profile; checksum verified with `sha256sum -c`.
- Arch package install validation in a clean container: `probraw --version`,
  `check-tools --strict`, `check-amaze` and `check-c2pa`.
