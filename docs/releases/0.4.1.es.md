# ProbRAW 0.4.1

ProbRAW 0.4.1 es una release correctiva Linux Arch/CachyOS para el flujo de
muestras Lab y la interfaz de la aplicacion.

## Precision De Muestras Lab

- Las muestras Lab guardadas pasan a pendiente en cuanto cambia el render
  actual.
- Los cambios de color, exposicion y contraste recalculan las lecturas guardadas
  desde valores actuales de pixel real antes de volver a publicar RGB/Lab.
- Los parches parciales de preview interactiva tambien disparan el refresco de
  muestras, evitando valores obsoletos tras cambios visibles de imagen.
- Los RGB de muestra se muestran como tripletas enteras estandar 0-255.
- Si no hay recalculo exacto a resolucion completa disponible, la UI mantiene la
  lectura pendiente en vez de publicar valores parciales.

## Interfaz

- La GUI usa ahora un tema gris oscuro neutro en todos los escritorios
  soportados, con independencia del tema del sistema.
- El idioma efectivo de la UI es espanol para evitar superficies con mezcla de
  idiomas mientras el catalogo de traduccion no este completo.
- Las explicaciones de precision y flujo se mueven a botones compactos de
  informacion cuando es posible.
- Se ha ajustado el contraste de texto en paneles, fichas, tablas y etiquetas de
  estado oscuras.
